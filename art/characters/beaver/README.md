# Beaver character asset

- Origin: original project work, created for Castor milestone 3b; not adapted from a third-party model.
- Author: Castor project author (procedural modeling and animation script authored in this project).
- License: project-authored; no external asset or source license applies.
- Attribution: none required.
- Editable source: `Beaver.blend`, reproducibly generated by `create_beaver.py` with Blender 5.2.3 LTS.
- Game export: `game/assets/characters/beaver/Beaver.glb` (binary glTF 2.0).
- Scale: Blender units are meters; feet touch the ground at y=0 in Blender. The model is about 1.1 m tall and 1.6 m from nose to tail.
- Orientation: the beaver faces Blender -Y; the Y-up glTF export places the nose at +Z in Godot. `prototype_actor.gd` rotates the visual node 180° around Y so the nose follows the actor's -Z forward convention and the carried item stays in front. The model origin is at the center of the feet.
- Materials: five simple node materials, no external textures.
- Rig: eight bones for root, body, head, tail, and four legs. Mesh parts have single-bone weights for maintainable stylized articulation.
- Actions: looping `Idle` and `Walk`, exported as separate glTF clips.
- Integration: instantiated by `game/scripts/prototype_actor.gd`; the gameplay capsule remains independent of the visible mesh.
- Validation: Blender export completed; Godot 4.7.2 imported the GLB and reported both clips and an eight-joint skin. Windows/device visual validation remains open.

The asset is a deliberately simple first production model. It communicates the beaver through its chestnut body, blunt light muzzle, paired incisors, and broad flattened tail. No texture or external reference image was incorporated.
